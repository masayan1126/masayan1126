# プロフィール
技術を手段と捉え、AIを武器に「アウトプットの量」ではなく **アウトカム（事業・ユーザー価値）** を最大化する。個人の生産性にとどまらず、AI駆動の仕組みを **チーム・組織全体へ展開** できるテックリードです。

---

## サマリー

MCPサーバー・APIの開発をテックリードとして推進。Claude Code を用いた Agentic Coding・オーケストレーション・フィードバックループ を実務フローへ組み込み、AIで開発速度と品質を底上げする仕組みを設計・運用しています。一方で、技術を目的化せず、企画・要件定義フェーズからプロダクト目線・ユーザー目線で一貫して開発を前に進めることを大切にしています。領域にとらわれないフルスタックな開発基盤を持つため、AIの出力を正しく評価・改善し、成果につなげられます。

---

## 提供できるバリュー

### 1. AIをアウトカムに変える「仕組み化」と組織への横展開

- Claude Code / MCP / Agentic Coding を実務フローに組み込み、**個人だけでなくチーム・組織全体**の開発速度と品質を底上げする仕組みを設計・運用できます。
- 仕様駆動開発 / Issue駆動開発をベースに、**AIエージェントが迷わず動けるコンテキスト設計** ができます。
- AIによってアウトプットを容易に量産できる時代だからこそ、「どれだけ作ったか」ではなく **「どんな価値・成果を生んだか」** を基準に判断・行動します。

### 2. 領域にとらわれないフルスタックな開発基盤

- フロントエンド・バックエンド・インフラを横断する**フルスタックな実装経験**を持ち、課題に応じて最適な技術を選択できます。
- クリーンアーキテクチャ、デザインパターン、自動テスト、パフォーマンスチューニングを実務に適用できます。
- AI活用と確かな開発基盤を**両輪**で持つため、AIの出力を鵜呑みにせず評価・改善し、品質を担保できます。
- MCPや決済、SAML認証など技術的難易度が高い要件に対しても優れたキャッチアップ能力で柔軟に対応できます。

### 3. 技術を手段とする、プロダクト/ユーザー目線の一貫した推進力

- 技術を目的化せず、プロダクト目線・ユーザー目線で課題解決につながる **提案 → 設計 → 実装 → 保守** まで一貫して推進できます。
- 要件が曖昧な段階でも、Issueや仕様に落とし込み、**実装可能な単位へ分解**できます。
- 企画・要件定義フェーズから関わり、ビジネス・ユーザー価値から逆算して開発を前に進めます。

### 4. 継続的なキャッチアップと、知見の発信・共有

- AI / Claude Code / MCP などの新しい技術動向を継続的にキャッチアップし、**実務で使える形に整理・検証**できます。
- YouTube・Zenn・勉強会LT を通じて知見を継続的に発信・蓄積し、**周囲やコミュニティへ積極的に共有**しています。
