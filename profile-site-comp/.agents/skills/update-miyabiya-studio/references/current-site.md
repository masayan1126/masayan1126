# 採用済みの構成

## トップと問い合わせ導線

- 検索・シェアではMiyabiya Studioを主役に、Masaya Nishigakiを添える。OGPは採用C「ドット絵のプロフィール」。白基調・採用書体で、アバター・曲線m・文字を中央の正方形内へ収め、横長・正方形の両方で見切れを防ぐ。faviconとスマホ保存用アイコンは採用済みの曲線mへそろえる。2026年10月28日の本人の選択に基づく。
- 屋号左のマークはB案「曲線のm」。黒1色、PC24px・スマホ20pxで表示し、屋号18pxとの組み合わせを保つ。

- トップのスクロール案内は採用C「スクロールの進行表示」。広い画面は本文列の右の縦レール、狭い画面・高さの低い画面は固定ヘッダー下の横バーと進捗率で示し、「スクロール」の文字は表示しない。本文・リンクを隠さず、読み上げで進捗を繰り返し通知しない。
- 短い自己紹介の後に、技術発信、YouTubeやSNSでの製品PR・タイアップ、個人開発、AI動画編集、登壇・社内勉強会、AI活用支援の順でまとめる。
- 技術発信と個人開発は別セクションにする。活動紹介のためだけの詳細ページや、統合済みページへ向かうナビゲーションは増やさない。
- 問い合わせ入口は共通ヘッダーへ集約する。各活動に相談ボタンを追加しない。お問い合わせページでは同じページへの問い合わせリンクを置かず、トップへ戻る手段を置く。
- ヘッダーはスクロール時も固定し、SNSアイコンをお問い合わせの左に並べる。フッターにもSNSアイコンを置き、コピーライトの名義はMiyabiya Studioにする。両方のYouTubeアイコンだけ赤色とし、ほかは無彩色を保つ。
- フッターは全7ページで画面下端へ固定する。高さに合わせて本文下部に余白を確保し、末尾の内容・フォーカス・旧見積もりの固定バーを隠さない。見積もりダイアログ内のフッターとは分けて扱う。

## 作品・イベント・公開ツール

- プロフィール画像はE案の背景透過・モノクロのドット絵を採用し、40pxで表示する。
- PR動画は、小さなサムネイルと作品名・視聴リンクを持つ、背景なしの縦型表示にする。見積もりリンクを作品カードのボタンとして詰め込まない。
- PR欄はPC・スマホとも、見出し、電卓アイコン付き「料金を見積もる」、制作動画の縦並びにする。
- 登壇は囲みカードにせず、イベントページのOGP画像と「登壇テーマ：…」のリンクを並べる。テーマ名は太字にしない。
- 拡張機能は実アイコンと正式名を表示し、各掲載ページへリンクする。アイコン位置、列幅、名称の行の高さをそろえる。
- 人数の数値そのものは、この資料へ複写せず、確認日付きのデータを正本にする。

## 見積もりとフォーム

- PR動画の料金シミュレーターと概算見積書の作成機能を維持する。
- 大きなダイアログで一問ずつ選び、最後に小計・合計・内訳を表示する。回答の選び直し、別の組み合わせの比較、共有URL、PDF、問い合わせへの引き継ぎを維持する。
- 別の組み合わせへの入口は、完成後の画面下の固定バーで気づけるようにする。
- 料金、税の扱い、要相談、修正回数などの条件は共通データを使う。デザイン変更で未確定の料金を確定・無料にしない。料金・条件は現在のデータと本人の指示から確認する。
- フォームは標準の自動入力、入力に合うキーボード、ラベル、入力内容の保持、送信状態を維持する。送信ボタンは「送信する」。不要な準備完了メッセージや長い流れの説明を復活させない。
- ボット対策は採用済みのTurnstileを維持する。デザイン確認のためにメールを実送信しない。
