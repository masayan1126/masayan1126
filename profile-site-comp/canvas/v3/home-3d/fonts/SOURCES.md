# Homepage typefaces

- Noto Sans JP, variable weight 100–900, Google / Adobe. SIL Open Font License 1.1.
  - https://github.com/google/fonts/tree/main/ofl/notosansjp
- Manrope, variable weight 200–800, Mikhail Sharanda. SIL Open Font License 1.1.
  - https://github.com/google/fonts/tree/main/ofl/manrope

The WOFF2 files are self-hosted. The Japanese font includes the characters used in the existing site copy and the studio controls. The Latin font includes Latin, punctuation and arrows. Variable outlines are retained, so no browser-synthesized bold is needed. Normal site builds use these prepared files and do not need network access or font-processing tools.
