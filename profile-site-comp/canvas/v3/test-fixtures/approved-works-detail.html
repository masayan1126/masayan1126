チャンネルの運営

AI関連の情報を発信するチャンネルを、企画から動画制作・公開・収益化まで一人で運営しています。Claude Codeを中心に、AIツールや開発者向けサービスを実際に使って紹介しています。企業の製品PR動画に加え、対談や共同企画もお受けしています。

動画制作の自動化・仕組み化

動画制作と公開の流れにAIを組み込み、本編とShortsを継続的に公開しています。

動画1本あたりの作業時間 約25〜37時間 → 約2〜3時間（約90%削減・撮影を除く）

大きく減ったのはShortsとスライド・台本で、削減分の7割ほどを占めます。週1本のペースなら、毎週3〜4日分の作業時間が空きます。残る2〜3時間は、骨子・タイトル・サムネイル・Shortsのタイトルを選ぶ時間と、スライドを承認する時間です。この判断はあえて人が行っています。

工程ごとの内訳

本編（10〜15分）1本とShorts 15本を作る場合

  1. 企画・骨子（章立て）

    手作業 1.5〜3時間 → 30〜40分

    AIが企画の意図から章立て案まで作成。並べ替えと修正だけを行う

  2. スライド20〜30枚と読み上げ台本

    手作業 6〜12時間 → 0分

    骨子からAIがスライドと台本を作成

  3. レビュー

    手作業 1〜1.5時間 → 30〜60分

    トーン・伝わりやすさ・デザイン・企画との整合をAIが先に確認。最後の承認だけを行う

  4. 撮影後の仕上げ（文字起こし・チャプター・概要欄・再生リストなど）

    手作業 4〜6.5時間 → 5分

    取り込みからメタデータの検証までを自動化。挿入位置と公開日を決めるだけ

  5. タイトルとサムネイル

    手作業 1.5〜2.25時間 → 20分

    AIが競合とキーワードを調べて案を作成。採用する案と画像を選ぶだけ

  6. 公開と告知（予約・カレンダー登録・コミュニティ告知・Studioの設定）

    手作業 1.5〜2時間 → 15分

    予約から設定・記録までを自動化。最終承認と結果の確認だけ

  7. Shorts 15本（区間選定・縦長への変換・テロップ・予約）

    手作業 8〜11時間 → 20〜30分

    区間選定から予約までを自動化。タイトルの採用だけを行う

合計 手作業 約25〜37時間 → 約2〜3時間（1本あたり約23〜34時間の削減）
