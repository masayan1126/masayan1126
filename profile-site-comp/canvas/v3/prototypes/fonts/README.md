# フォント5案の比較

`python3 canvas/v3/build_review.py`で既存レビューに「フォント5案」を生成します。表示先は`http://127.0.0.1:8776/review.html`です。公開版と採用済みのフォントは変更しません。

- 5書体とも本文400・見出し700、文字サイズ24・18・14pxで比較します。
- フォントはGoogle Fontsの公式配布から取得しています。各OFL原文・取得元・ファイルのハッシュは`assets/`に保存しています。
- 配布元が静的フォントを返す場合と可変フォントを返す場合があります。可変フォントはCSSの`font-weight`で400／700を選びます。
- 実際の7ページを複製し、トップ・お問い合わせ・見積もりを同じ画面で切り替えられます。フォームは送信しないプレビュー設定を引き継ぎます。

`assets/`の書体は、比較時点の7ページとサンプルに必要な文字へ配布元で絞った比較用ファイルです。新しい文章や送信エラーの文字が増えた場合は`python3 canvas/v3/prototypes/fonts/fetch_fonts.py`で再取得してください。採用案を本番へ反映するときは、日本語全体を扱える配信方法と読み込み量を確認し、比較用サブセットをそのまま転用しないでください。
