# 主な活動をまとめたサイト

本人が重視するAI活用支援、製品PR・タイアップ、登壇・社内勉強会、技術発信、個人開発を中心に、サイト全体を再構成しています。2026年10月26日の「B, D, E, F を重視してるので、その感じで全体をこうし直してみて」が根拠です。

本人の自己紹介の順に、技術発信→PR→個人開発→AI動画編集→登壇を並べます。AI動画編集は独立した見出しにし、既存のAI活用支援は末尾に残します。2026年10月27日の本人指示を反映した6つの見出しです。回答原文と配置案の正本は `../content-interview/content-plan.json` です。

屋号リンクには独自のMモノグラム（PC24px・スマホ20px）を添えます。文字は見出しと同じ18pxとし、スマホでも小さくしません。マークは装飾として読み上げから除外し、リンク名は「Miyabiya Studio」を維持します。スマホではお問い合わせの矢印を省き、1段の配置と44pxの操作領域を保ちます。

ヘッダーは屋号（トップへのリンク）とお問い合わせだけの1段構成です。4活動のメニューは削除し、内容はトップの6つの見出しで確認できます。フッターは著作権表記のみです。プロフィール・実績・その他の対応業務のページや内容は維持しています。問い合わせの入口はヘッダーのみとし、本文の相談ボタンは置きません。

## デザイン

自己紹介文の下にYouTube・X・Instagram・GitHubのアイコンリンクを並べます。20pxの無彩色アイコンに44px四方の操作領域を設け、読み上げ名・新しいタブの案内・キーボードフォーカスを維持します。SVGはSimple Iconsから取得し、出所・固定コミット・ライセンスを `icons/simple-icons/` に保存しています。

PR欄の見出し下に「お見積りはこちら」のテキストリンクを置きます。PC・スマホで同じ配置にし、本文と同じ14px・通常の太さ、44pxの操作領域とフォーカス表示を維持します。

PR動画は、2026年10月27日に採用したA案の背景なし縦型です。画像160px・全体200pxとし、題名と視聴リンクを下へ並べます。灰色の囲み・枠・影は使いません。

トップの個人紹介は、名前18px・肩書き14px・プロフィール画像40pxでまとめ、画像と文字の間隔を12pxに揃えます。

トップの自己紹介・活動説明は、本人の指定により体言止め中心の短い表現にします。実績の数値・対象本数・撮影除外の条件は残します。料金や取引条件の説明は短縮の対象にしません。

採用済みA案の文章中心のレイアウトを維持します。UIは白・黒・グレー、写真・サムネイル・埋め込みは元の色です。区切りは余白で表現し、リンクに下線を付けません。キーボードのフォーカス表示を残します。

PC・スマホ共通で、ページタイトル・主な数字は24px、見出し・名前・屋号・入力欄は18px、本文・補足・メニュー・ボタンは14pxです。登壇画像下のテーマだけは、本人指定で12pxにします。主操作は黒背景・白文字、補助操作は白背景・黒文字に揃えます。

お問い合わせはトップと同じ白背景と横幅に揃え、フォームの囲みと二重の余白を外します。必須・任意は通常の文字、送信ボタンは黒背景・白文字です。入力項目・選択肢・送信処理は維持します。

見積もりページとシミュレーターは `pricing-local.css` でトップの見た目へ揃えます。白背景と24・18・14pxの文字を使い、質問・回答・明細は余白で整理します。選択中の項目だけ薄いグレーで示し、チェックとキーボードのフォーカスを残します。ダイアログ、完成見積書、6通りの比較、宛名入力を同じボタンと文字のルールに揃えます。料金・計算・共有URL・PDF・問い合わせの引き継ぎは変更しません。

AI活用支援の支援内容と実績は5項目の箇条書きに整理します。YouTube制作の工数削減と一般動画編集の対応範囲は、独立したAI動画編集欄にまとめます。その他の対応業務は開閉して確認できます。

登壇欄はイベントページのOGP画像と「登壇テーマ：」付きリンクを横並びにします。カードの背景や枠は付けず、リンク文は12px・通常の太さ、行高1.6です。スマホでは1列に折り返します。

活動紹介は、見出し・本文・詳細リンクの文字の左端を揃えます。活動内の間隔は6〜10px、活動間はPC36px・スマホ32pxとし、近接と余白でまとまりを表現します。詳細リンクは44pxの操作領域を維持します。

## 生成元と確認

`content.py` がトップを含む本文と共通ヘッダーを生成し、`site_copy.py` がメタ情報とUI文言を管理します。以前の比較3案は `../compact-patterns/` に残し、本体の編集では変更しません。`compact.css` が幅と余白、`../typography/scales.mjs` が文字サイズを管理します。

`build.py` → `canvas/v3/build_review.py` の順にローカル版を生成し、`validate.py` でリンク・画像・料金DOM・フォームの互換性を確認します。旧 `/media/`・`/activities/`・`/services/` はトップの該当欄へ転送するだけにし、独立した本文を生成しません。

生成先は `output/editorial-concept/site/`、表示先は `http://127.0.0.1:8776/` です。既存レビュー `/review.html` の先頭でも確認できます。8777番は以前のリンクとの互換性のため残します。

見積もりの料金データ・計算・PDFと旧URLの処理は維持します。ローカルでは問い合わせ送信を防ぎ、Analyticsを除去します。公開では実際のAPI・GA4・検索設定を使います。Gmailは変更しません。

2026年10月27日の公開承認により、`build_public.py` から `publish.py` を呼びます。毎回ベースを別フォルダへ生成してから変換するため、公開後も次回ビルドとローカル確認を再現できます。公開ではPDF・過去の料金表を含む完全な配信物を生成し、加工したモジュールとCSSへ新しいハッシュを付けます。確認記録は `output/public-release/` に保存します。
