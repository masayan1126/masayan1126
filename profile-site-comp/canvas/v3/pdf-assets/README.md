# PDF font

Noto Sans JP, regular weight (400), instantiated from the upstream variable TrueType font with fontTools 4.60.2.

- Source: https://github.com/google/fonts/tree/main/ofl/notosansjp
- License: SIL Open Font License 1.1; see OFL.txt.
- The font is downloaded from this site only when a visitor requests a PDF.
- The complete font is embedded to avoid missing Japanese glyphs in fontkit subsets.

PDF runtime packages are pinned in package-lock.json: pdf-lib 1.17.1 (MIT) and @pdf-lib/fontkit 1.1.1 (MIT).
