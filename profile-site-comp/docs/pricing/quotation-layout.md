# 概算見積書の記載項目を整えました

2026年9月6日に、freeeと弥生の公式解説を確認しました。宛先・発行元・明細・金額・取引条件を分ける構成を採用しています。

見積書は、発注前に内容と金額を確認するための書類です。見積番号は書類の管理に使います。[freeeの解説](https://www.freee.co.jp/kb/kb-invoice/estimate/)

数量・単価・金額の明細に加え、納期や支払条件も記載します。[弥生の解説](https://www.yayoi-kk.co.jp/seikyusho/oyakudachi/quotation-how-to-write/)

## 発注を検討する方が使う書類として整えました

| 項目 | 採用した内容 |
| --- | --- |
| 書類名 | 金額に幅があるため、「概算見積書」と明記します。 |
| 宛名 | お客様が会社名・お名前を入力し、御中・様を選べます。未入力の場合は「お客様」と記載します。 |
| 見積日 | ダウンロード当日の日付を、日本時間で記載します。 |
| 発行元 | Miyabiya Studio、Masaya Nishigaki、contact@msyn.meを記載します。住所・電話番号は載せません。 |
| 件名 | PR動画制作と記載します。 |
| 明細 | 選択した作業について、数量・税込単価・税込金額を記載します。 |
| 合計 | 税込の明細を合計し、その内訳として消費税相当額10%を表示します。税抜小計の表示は省きます。金額は変更しません。 |
| 取引条件・備考 | 1ページ目に金額と対象動画を記載します。2ページ目に取引条件と作業範囲をまとめます。 |
| 有効期限 | 概算PDFには期限を設けません。正式見積もり時に提示する方針を、ユーザーが確認済みです。 |
| 見積番号 | 自動採番による管理をしていないため、任意の番号は追加しません。 |
| フッター | 見積もりページのURLを印字します。PDF内でクリックすると、選択内容と料金表を引き継いだページを開きます。 |

料金表の更新日は、引き続き見積もりページに表示します。PDFのリンクには元の料金表と選択内容を引き継ぎます。

書類の配置は公式の見本を参考にしました。概算の表記と有効期限は、ユーザーの指定に合わせています。

## 指摘内容を現行の料金・条件と照合しました

2026年9月6日に、見積書への追加指摘を反映しました。本文は黒、罫線と背景はグレーで統一しています。

| 指摘 | 反映内容と判断理由 |
| --- | --- |
| 税抜・税込の混在 | 明細・合計を税込で統一し、内税を明示しました。編集15,000円・サムネイル5,000円は税込指定です。切りのよい税抜額へ変更すると、承認済みの総額が変わります。 |
| インボイス登録 | Webに記載済みの未登録の表記を、PDFにも加えました。 |
| チャンネル掲載 | 見積額に掲載を含み、掲載料の別途請求がないと明記しました。削除済みの掲載費20,000円は追加しません。 |
| 修正・追加料金 | 軽微修正2回まで料金内、3回目以降5,500円（税込）を記載しました。30分超・撮り直しは要相談とする既存条件を使います。20分超の自動加算は追加しません。 |
| 発行元・見積番号 | 確認済みの屋号・氏名・メールを使います。住所・電話番号・管理用の番号は追加しません。 |
| 支払条件 | 原則月末締め・翌月末払いを掲載しました。振込手数料の負担者や振込先の案内は未確認なので、追加しません。 |
| 権利・掲載期間 | 著作権は個別契約、二次利用は要相談と明記しました。掲載を終了する条件も既存の案内から転記しました。 |
| 事前検証 | 機能・操作手順と、動画で紹介する内容を検証する作業だと補足しました。アカウントはお客様にご用意いただきます。 |
| キャンセル料 | 正式見積もり総額に対する30%・50%・100%の既存条件を記載しました。 |
| レポート | 再生数・視聴維持率を記載しました。計測用リンクはお客様から提供がある場合に掲載します。クリック数の報告は約束しません。 |

インボイスの経過措置も国税庁の最新資料を確認しました。2026年10月からの控除可能割合は、改正前の50%から70%へ見直されています。PDFには未登録の事実を記載し、取引先ごとの控除額は計算しません。[国税庁の令和8年度税制改正特集](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm)
