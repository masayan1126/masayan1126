# Miyabiya Studioの作業ルール

このディレクトリのサイト更新・デザイン・情報設計・文言・操作を変更するときは、必ず[update-miyabiya-studio](.agents/skills/update-miyabiya-studio/SKILL.md)を読んで適用する。

基本方針は「シンプル、要素や内容、セクションのまとまり、ゴチャつきがない」。余白・近接・整列で関係を示し、必要な情報を選んで載せる。詳細な方針はスキルを正本とし、ここへ重複して書かない。

理由：このセッションで採用した方針を次の更新でも保ち、古い比較案や装飾を戻さないため。

- 最新の本人の指示を優先する。現在の構成と生成元はスキルの参照資料、作業状況は[TODO.md](TODO.md)、運用の詳細は[README.md](README.md)で確認する。
- スキルの正本は`.agents/skills/`。Claude CodeとCodexの入口は同じ正本へのリンクにする。このディレクトリに`CLAUDE.md`を作らない。
- サイト固有の料金・数値・採用方針をグローバルのスキルやメモリへ複写しない。
