# Miyabiya Studio サイト

作業前に [README.md](README.md) を読み、そこにあるルールに従うこと。特に次の2つは必ず守る。

- **トップページは詳細ページの抜粋にする。** トップページにだけある情報を作らない。トップページを直したら、同じ変更を詳細ページにも入れる。詳細は README の「トップページと詳細ページの内容をそろえる」
- 実績の数字には計算根拠を添える。詳細は README の「実績の数字を書くとき」

変更後は `npm run build`、`npm test`、`python3 canvas/v3/validate_home.py` を通してから報告する。
