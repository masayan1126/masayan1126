# デザインシステムグリーン

スライド向けのグリーン系デザインシステムです。既存の design-system から再利用したのは、テーマカラーとして使われていた5段階のグリーンだけです。

## 継承した色

- Green 900: #1D3A32
- Green 800: #264C41
- Green 700: #2F5D50
- Green 500: #54786C
- Green 100: #E6EDE9

既存の書体、余白、レイアウト、カード、猫素材、RPG表現は継承していません。白、黒、グレーは新しい無彩色です。

## 使い方

1. deck-template.html を複製します。
2. slides.css を読み込みます。
3. 内容に合う8種類のレイアウトから選びます。
4. PRACTICES.md の規則をすべて適用します。
5. validate.mjs を実行してから納品します。

## レイアウト

| レイアウト | 用途 |
| --- | --- |
| cover | 表紙。題名と資料の構成を最小限で示す |
| section | 章扉。現在地と章の結論を示す |
| claim-visual | 主張と、それを説明する図を並べる |
| comparison | 同じ観点で二つを比較する |
| process | 番号と接続線で説明順を示す |
| data | グラフ、直接ラベル、読み取りを近くに置く |
| visual | 関係図と短い説明を組み合わせる |
| closing | 結論と次の行動を示す |

## 基本仕様

- 画面: 1920×1080、16:9
- 外側余白: 左右120px、上下88px
- 表紙タイトル: 96px
- スライドタイトル: 58px
- 本文: 28px
- 情報階層: 三段階以内
- 配色: グリーン一色と無彩色
- アイコン: 2px線の線画。説明に必要な場合だけ使う
- 図表: 重要系列だけをグリーンで強調し、値を直接表示する

## ファイル

- index.html: デザインシステムの見本帳
- deck-template.html: 見本入りのデッキ雛形
- slides.css: スライドの共通スタイル
- tokens/: 色、書体、余白のトークン
- icons.svg: 線画アイコンのスプライト
- PRACTICES.md: 確定した共通規則
- manifest.json: 再利用範囲と仕様の機械可読情報
- validate.mjs: 品質検証
- build.mjs: 成果物の再生成

## 検証

次のコマンドを、このディレクトリで実行します。

    node validate.mjs

検証では、継承色、規則数、レイアウト数、発表者ノート、主張タイトル、グラフの直接ラベル、禁止された旧表現の混入を確認します。
