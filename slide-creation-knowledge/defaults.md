# スライドの既定値

[practices.md](./practices.md) の規則を、実際のスライドへ当てはめるときの具体値。
規則そのものはデザインに依存しないため、数値はこのファイルへ分けている。

別のブランドやテーマで作る場合は、このファイルだけを差し替える。

## 見出しの型

タイトル（最大・黒）→ 補足説明（小・黒）→ 罫線（主色）の順に、左揃えで置く。

分類ラベルを上に小さく置き、その下へ大きい補足文を置く形にしない。
分類ラベルを残す必要がある場合は、タイトルより小さくする。

## 文字色

| 用途 | 値 |
| --- | --- |
| タイトル | `#222222` |
| 補足説明・分類ラベル | `#222222` |
| 主色（下線・罫線のみ） | `#1A4FA0` |
| 背景 | `#FFFFFF` |

主色は文字に使わない。白背景に対するコントラストは `#222222` が15.9:1、`#1A4FA0` が7.9:1で、
どちらも WCAG 2.2 の最高基準（7:1）を上回る。

## 太さ

| 用途 | 値 |
| --- | --- |
| タイトル | 800 |
| 補足説明・分類ラベル | 700 |

主従は太さではなく大きさで付ける。

## 大きさ（16:9・幅1280pxのとき）

| 用途 | 枠幅に対する比率 | 実寸 |
| --- | --- | --- |
| タイトル | 6.2% | 約80px |
| 補足説明 | 2.4% | 約31px |
| 分類ラベル | 1.5% | 約19px |

別の幅で作る場合も比率を保つ。

## 字間・行間

| 用途 | 値 |
| --- | --- |
| タイトルの字間 | -0.045em |
| タイトルの行間 | 1.24 |
| 補足説明の行間 | 1.6 |

## 間隔（16:9・幅1280pxのとき）

| 位置 | 枠幅に対する比率 | 実寸 |
| --- | --- | --- |
| タイトル → 補足説明 | 1.3% | 約17px |
| 補足説明 → 罫線 | 4.6% | 約59px |
| 枠の内側余白 | 6.5% | 約83px |

タイトルと補足説明を1つの群にし、罫線をその外へ置く。3つを等間隔に並べない。

## 罫線

| 項目 | 枠幅に対する比率 | 実寸 |
| --- | --- | --- |
| 幅 | 11% | 約141px |
| 太さ | 0.65% | 約8px |

左端をタイトルの左端にそろえる。
